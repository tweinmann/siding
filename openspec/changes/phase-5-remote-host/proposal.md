## Why

A laptop runs only so many stacks. A remote Docker host takes the load while the developer
keeps the same names and the same commands.

## What Changes

Roadmap v0.5:

- Stacks on a remote Docker host, chosen through a Docker context.
- A local forwarder so that `*.localhost` reaches stacks on the remote host.
- A `HOST` column in `siding ps`, from the `dev.siding.machine` label.
